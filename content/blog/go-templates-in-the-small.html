Go templates are deceptively capable. With a handful of helpers and a clean file structure, you can ship a multi-page portfolio without a framework.

Keep it predictable

I like to separate layout, data, and content. Templates handle the structure, handlers pass typed data, and HTML snippets live as static files.

type PageData struct {
  Title string
  Projects []Project
}

Ship, then polish

Start simple, publish early, and iterate. You can always refine visuals after the content is in place.
