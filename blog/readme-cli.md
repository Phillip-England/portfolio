# Usecase

I am navigating a project and need a reminder on how things work. Easy, I simply run:

```bash
readme
```

My browser opens up to `localhost:45173` and there is the inforation I need with nice dracula highlighting.

# The Repo

This project is located at, `https://github.com/phillip-england/readme`

It is written in `go` and should be fairly easy to install.

I really tend to favor `go` for it's simplicity, and cli installation is a good example.

# The Inspiration

I noticed I was constantly going to `github` to read about my own projects. I thought to myself, "Why can't I just have this on my own browser."

This is a good example of making use of tools you know. This is a simple vibe-coded project, but since I have made use of goldmark, coloring code blocks, and html to markdown conversions, this project was quick to spin up and it works.
